# TaskFlow - AI-Powered Collaborative Platform

TaskFlow is a modern, real-time productivity platform enhanced with AI capabilities and collaborative tools.

## 🚀 Advanced Features

### 🤖 AI-Powered Assistant
- **Floating AI Chatbot**: ChatGPT-style interface for summarizing progress and generating task descriptions.
- **AI Auto Task Breakdown**: Automatically generate subtasks for complex tasks with one click.

### 💬 Real-time Collaboration
- **Slack-style Team Chat**: Instant messaging with typing indicators and online user tracking.
- **Collaborative Whiteboard**: Real-time canvas for brainstorming with shapes, text, and sticky notes.
- **Presence Awareness**: See who's online and what they're working on in real-time.

### 📊 Smart Analytics
- **Productivity Dashboard**: Visual insights into task velocity, team workload, and project status using Recharts.
- **KPI Cards**: Real-time tracking of completion rates and active participation.

### 🎙️ Voice Control
- **Voice Command System**: Control your workspace using your voice (e.g., "Create task...", "Go to whiteboard").

### 🏗️ Core Features
- **Interactive Kanban Board**: Smooth drag-and-drop task management.
- **Real-time Sync**: Powered by Socket.IO for instant updates across all users.
- **Operation Feed**: Live log of all project activities.
- **Smart Alarms**: Schedule tasks and receive notifications.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Recharts, Fabric.js, Lucide Icons.
- **Backend**: Node.js, Express, Prisma, SQLite, Socket.IO.
- **AI**: Simulated AI service layer (ready for OpenAI integration).

## 🚦 Getting Started

1. **Backend**:
   ```bash
   cd backend
   npm install
   npx prisma db push
   npm run dev
   ```

2. **Frontend**:
   ```bash
   cd frontend
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend development server:
   ```bash
   npm run dev
   ```
   *The app runs on `http://localhost:5173`*

## How to use
- Open the application in two different browsers (or incognito windows).
- Register an account on both windows and log in.
- Create tasks, drag them around, and see them sync instantly.
- Check the real-time operations feed on the right sidebar.
